# ci-cd-final-project

## Continuous Integration and Continuous Delivery (CI/CD) Final Project

This project demonstrates a CI/CD pipeline using GitHub Actions, Python, flake8, nose unit tests, Tekton, Buildah, and Red Hat OpenShift.

The pipeline automates source code checkout, dependency installation, code linting, unit testing, container image building, and application deployment.
